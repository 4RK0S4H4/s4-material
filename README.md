# S4 Orion

A personal design language built on Material 3 Expressive, with a glass layer for floating chrome. It is the successor to the S4 Material skill.

**Live site:** https://4rk0s4h4.github.io/s4-material/ (demos and reference)

## Status

S4 Orion is being built phase by phase. The decision log lives in [`docs/decisions/`](docs/decisions/).

| Phase | What | State |
|---|---|---|
| 1 | Audit of S4 Material 1.3 and decisions | In review ([explorations](https://4rk0s4h4.github.io/s4-material/)) |
| 2 | Repo structure | Not started |
| 3 | Tokens | Not started |
| 4 | Glass layer | Not started |
| 5 | Claude skill | Not started |
| 6 | Demo and review | Not started |

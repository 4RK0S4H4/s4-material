# Components

Reference implementations of S4 Orion components. Each one is plain HTML and CSS built only from tokens, with a small
shared runtime for theming and motion. React wrappers are added only where state or motion make them worth having.

## Using them

```html
<link rel="stylesheet" href="components/orion.css">      <!-- tokens + base + every component + glass + motion -->
<script src="components/assets/icons.js"></script>     <!-- icon registry (semantic names) -->
<script src="components/orion.js"></script>              <!-- runtime: theme, motion, every component's behaviour -->
```

`orion.css` and `orion.js` are generated by `npm run build` from the folders below; edit the folders, never the bundle.
Browse every component on the [gallery](https://4rk0s4h4.github.io/s4-material/components/).

## Layout

```
components/
├── base/             cascade layers, Inter, element defaults, type utilities, focus ring, the shared state layer
├── core/core.js      S4 runtime: registry and auto-init, motion helpers, icons, theme
├── motion/           transition patterns: container transform, unfold, shared axis, slide from edge
├── glass/glass.css   the glass layer (decision 0004)
├── <component>/      <component>.css, <component>.js (if it has behaviour), <component>.html (reference page), README.md
├── icons/            names.json (vocabulary) and the Solar source set
├── assets/           inter-variable.woff2, m3color.js, icons.js (generated)
├── index.css         development entry (imports every file); index.html is the gallery
├── orion.css, orion.js   generated bundles
└── CONVENTIONS.md    the rules every component follows
```

Core set (decided in Phase 1): app shell (nav rail and nav bar), top app bar, buttons (filled, tonal, outlined, text,
elevated), icon button, connected button group, FAB and extended FAB, card, pane, list (including segmented and grouped),
data table that becomes a list on phones, divider, text field (filled and outlined, including select and textarea), switch,
checkbox, radio, chips (filter, assist, input), slider, search bar, tabs, menu, dialog, bottom sheet, side sheet, snackbar,
tooltip, badge, status pill, progress (linear and circular), color swatches.

Left out of 1.0 (can come back later): date and time pickers (native inputs cover them), carousel, shape morph library,
FAB menu, split button, swipe to dismiss, inspector layout, rolling numbers.

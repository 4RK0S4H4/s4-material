Components / Chip

Chips are compact elements for filters, choices, entered values and quick actions. Filter chips narrow a list; input chips show values someone entered, like tags on a bill; assist chips start a related action; suggestion chips offer likely replies or values. Put chips in a .s4-chip-set.

Filter

Multi-select by default. Selected chips turn secondary-container and a check slides in. With the keyboard: Tab, then Space.

Showing: Utilities

Single Choice and Scrolling

data-select="single" keeps exactly one chip selected. data-scroll keeps the set on one scrolling row; narrow the window to see it scroll.

Input

Tags entered for this bill. The remove button fires s4-remove and the chip collapses away. An avatar can lead.

Assist and Suggestion

Assist chips have a primary-colored leading icon. data-elevated lifts a chip off busy backgrounds.

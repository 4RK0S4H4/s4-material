Components / FAB

The floating action button holds the single most important action on a screen, like Add Bill. Use one per screen at most. It always shows an icon; the extended FAB adds a label and suits screens where the action isn't obvious from the icon alone.

Sizes

FAB (56), medium (80) and large (96). Corners grow with the size: large, large-increased, extra-large.

Colors

Primary container is the default. Pick the role that fits the screen's color; containers are calmer, the base colors stronger.

Extended

Add .s4-fab-label. The label is title medium, title large and headline small for the three sizes. data-collapsed folds it back to the icon, for example while a list scrolls: try the button.

Placement

data-fixed pins the FAB 16dp from the bottom end corner, above the safe area. The FAB on this page is pinned.

Components / Icon Button

Icon buttons run a single action with one icon: edit a bill, open a menu, mark a favorite. The standard icon button has no container and suits toolbars and rows; filled, tonal and outlined add emphasis. Every icon button needs an aria-label. Press and hold to see the shape morph.

Variants

Standard, filled, tonal, outlined. The second row is disabled.

Toggle

data-toggle with aria-pressed. Selected icon buttons take the full color and swap shape (round to square). Optional data-icon-on swaps the icon and data-label-on the label. Top row unselected, bottom row selected.

Sizes

Extra small (32) to extra large (136); small (40) is the default. Every size keeps a 48dp touch target.

Width and Shape

data-width="narrow" or "wide" change the container width; data-shape="square" uses the square corner for the size.

In a Row

Standard icon buttons for per-row actions. A delete stays a plain icon button, not red.

Components / Navigation Rail

The navigation rail holds the top-level destinations on wider windows (840 and up), at the side of the screen. It can carry a menu button that expands it, and the screen's main action as a FAB. It uses the same .s4-nav-item markup as the navigation bar, so an app shell can show either.

Collapsed and Expanded

Collapsed: 96dp, label under the icon. Press the menu button to expand: the rail widens, labels move beside the icons inside a pill that spans both, and the FAB shows its label. data-expanded starts it open.

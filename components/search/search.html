Components / Search

The search bar finds things on the current page. It filters as you type: no Search button, no submit. A clear button appears once there's text; Escape clears too. Put it at the top of the content it filters.

Live Filter

data-filter="#bill-list" hides the list items that don't contain the text (ignoring case and accents: try "societe"). data-filter-empty shows a message when nothing matches. The bar fires s4-change with the value either way.

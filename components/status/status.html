Components / Status

A status pill names the state of a thing: a bill, a payment, a sync. The label always says the status in words; the tone and the optional dot only reinforce it, so it never relies on color. Status pills aren't buttons: to filter by status, use a filter chip.

Tones

Neutral by default; data-tone picks the primary, secondary, tertiary or error container.

With a Dot or Icon

data-dot adds a leading dot in the text color. An icon can lead instead.

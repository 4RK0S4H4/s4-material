Components / Swatches

Swatches let people pick the seed color the whole app is themed from, like Android's Wallpaper & style. Each swatch previews the palette its seed makes. Mono is S4 Orion's default monochrome theme. Pick one: the page re-themes, and the Color control in the bar above stays in step.

Theme Color

data-theme-seed on the group: a click calls S4.theme({ seed, variant: 'vibrant' }). Tab in, then use the arrow keys.

Picker Only

Without data-theme-seed the group is a plain single choice that fires s4-change { seed }, for example a category color.

Utilities color: #0b57d0

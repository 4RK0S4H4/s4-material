Components / Table

Data tables compare rows across columns: bills, payments, invoices. Every figure uses tabular digits and numbers are right-aligned. On compact screens (the table's space under 600) each row becomes a stacked block with column names, so phones never scroll sideways. Tables are solid content surfaces, never glass.

Sortable, Selectable, Clickable

Sort buttons in the headers cycle ascending, descending and the original order. The checkbox column selects rows (the header box selects all, and shows indeterminate for some). Rows with tabindex="0" open on click or Enter. data-sticky keeps the header in view while the rows scroll.

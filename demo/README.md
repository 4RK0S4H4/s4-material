# Demo

`demo/index.html` is one showcase page that uses every S4 Orion component, built only from the skill and the tokens.
It's the Phase 6 test: after it's built, it's reviewed against the skill's rules, and any drift is fixed in the skill's
wording rather than in the demo. Published at https://4rk0s4h4.github.io/s4-material/demo/.

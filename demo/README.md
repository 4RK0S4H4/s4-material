# Demo

`demo/index.html` is **Pocket Ledger**, one showcase app that uses every S4 Orion component, built only from the skill
(`skill/s4-orion/`) and its assets. Findings from reviewing it against the skill are in
[`docs/decisions/0005-phase-6-review.md`](../docs/decisions/0005-phase-6-review.md). Published at
https://4rk0s4h4.github.io/s4-material/demo/. The `orion.*`, `icons.js`, `m3color.js` and font files here are copies of
`skill/s4-orion/assets/`; refresh them after each build.

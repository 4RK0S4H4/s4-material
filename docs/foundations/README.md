# Foundations

Written: color, typography, shape, spacing, elevation, motion (Phase 3), glass (Phase 4). Accessibility (Phase 4).

- `color.md`: seed, scheme variants, roles, contrast levels, monochrome default
- `typography.md`: Inter, the M3 type scale, emphasized weights, numbers and tabular figures, capitalisation
- `shape.md`: the M3 Expressive corner scale and which components use which step
- `spacing.md`: the 4dp grid, margins, gaps, density and touch targets
- `elevation.md`: no shadows; tonal surfaces and glass carry depth
- `motion.md`: springs, the calm variants, and the transition patterns (container transform, emerge for menus, shared axis, slide from edge)
- `glass.md`: where glass is allowed, stacking limits, contrast guarantees and fallbacks
- `accessibility.md`: contrast, focus, targets, reduced motion and transparency, forced colors

# The S4 Orion skill

`skill/s4-orion/` is a Claude skill: drop it into Claude (or package it) and Claude applies S4 Orion to any app or page.

```
skill/s4-orion/
├── SKILL.md        under ~500 lines: trigger description, philosophy, decision rules, common mistakes, a worked example
├── references/     loaded only when needed. patterns.md is written by hand; components, tokens, icons and the
│                   foundation docs are GENERATED by scripts/build.mjs from the repo, so they can't drift
├── assets/         GENERATED: orion.css, orion.js, icons.js, m3color.js, Inter
├── scripts/        check.mjs (Playwright page checker), inline.mjs (one self-contained HTML file)
└── evals/          test cases in skill-creator's format (prompt.md, case.yaml, graders/)
```

Edit by hand: `SKILL.md`, `references/patterns.md`, `scripts/`, `evals/`. Everything else comes from `npm run build`
(and `npm run check` fails if it's stale).

**Install:** download [`dist/s4-orion.skill`](dist/s4-orion.skill) and add it in Claude (Settings → Capabilities → Skills),
or copy `skill/s4-orion/` into `~/.claude/skills/`. Re-package after changes with skill-creator's `package_skill.py`
(`python -m scripts.package_skill <repo>/skill/s4-orion <repo>/skill/dist`); evals are left out of the package.

Written in Phase 5. It replaces the S4 Material skill.
